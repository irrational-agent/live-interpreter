# live-interpreter

Синхронний перекладач для командного рядка. Ти говориш у мікрофон українською, а програма за секунду-дві
промовляє те саме японською або іншою мовою. Озвучувати переклад вона може готовим голосом ElevenLabs або клоном
твого власного голосу.

## Як це працює

Програма передає звук із мікрофона в Scribe, сервіс розпізнавання мовлення від ElevenLabs. Scribe повертає текст
ще під час мовлення, і програма показує його в рядку з трьома крапками. Коли ти робиш паузу (за замовчуванням 0,7 с),
Scribe вважає фразу завершеною й надсилає її остаточний текст.

Завершену фразу перекладає Claude. Разом із нею програма передає три попередні фрази, щоб переклад тримав
зв'язок із тим, що вже прозвучало. Claude повертає переклад частинами, і щойно в ньому закінчується речення,
програма відправляє це речення на озвучення в ElevenLabs. Звук починає грати з перших байтів, які приходять у
відповідь, тому перше речення звучить ще до того, як Claude допише решту.

Розпізнавання, переклад і озвучення працюють паралельно, тож наступну фразу програма слухає вже тоді, коли
попередня ще перекладається.

Перекладати слово за словом програма не намагається. В японській дієслово стоїть у кінці речення, тому переклад
можна почати лише тоді, коли думка вже прозвучала. Через це переклад іде на фразу позаду мовця, як і в живого
синхронного перекладача.

На тестових фразах звук починався через 1–2 с після того, як Scribe завершував фразу. До цього додається сама
пауза, за якою Scribe розуміє, що фраза закінчилась.

## Підготовка

Програмі потрібні два ключі. Ключ ElevenLabs відповідає за розпізнавання й озвучення, а ключ Claude API — за
переклад. Обидва зберігаються у файлі `.env.local` у теці проекту, який не потрапляє в git. Записати ключ можна
скриптом, який питає його в терміналі й не показує на екрані:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File C:\projects\live-interpreter\scripts\set-key.ps1
```

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File C:\projects\live-interpreter\scripts\set-key.ps1 -Name ANTHROPIC_API_KEY
```

Зібрати програму:

```powershell
cargo build --release
```

Готовий файл лежить у `target\release\live-interpreter.exe`. Ключі він шукає в `.env.local` поточної теки або
теки проекту, тож запускати його можна з будь-якого місця.

## Запуск

```powershell
.\target\release\live-interpreter.exe run
```

За замовчуванням програма перекладає з української на японську, перекладає моделлю Claude Opus 5.5 і озвучує
голосом George. Мову, голос і пристрої можна змінити параметрами:

| Параметр | Що робить |
|---|---|
| `--to en` | перекладає на іншу мову (код ISO 639-1: `en`, `de`, `ko`, `zh`…) |
| `--from en` | слухає іншу мову |
| `--voice "Мій голос"` | озвучує вибраним голосом, зокрема твоїм клоном |
| `--headphones` | слухає мікрофон і тоді, коли звучить переклад |
| `--silence 1.0` | змінює паузу, після якої фраза вважається завершеною |
| `--turn-prediction` | завершує фразу тоді, коли модель вирішить, що думка закінчена, а не на першій паузі |
| `--model claude-haiku-5-5` | перекладає швидшою моделлю |
| `--tts-model eleven_v4` | озвучує якіснішою, але повільнішою моделлю |
| `--input-device FIFINE`, `--output-device MR710` | вибирає мікрофон і вихід звуку за частиною назви |
| `--input-file запис.wav` | бере мову з файлу замість мікрофона |
| `--save-output out\переклад.wav` | зберігає все озвучене у файл |

Список пристроїв показує команда `devices`, а список голосів акаунта — команда `voices`.

**Луна.** Якщо переклад звучить із колонок, мікрофон чує його й передає на розпізнавання, і програма почала б
перекладати сама себе. Щоб цього не сталося, вона не слухає мікрофон, поки звучить переклад, і ще 0,4 с після нього.
Через це слова, сказані в цей час, губляться. У навушниках цієї проблеми немає, тому з ними запускай програму з
`--headphones` і говори без зупинок.

**Швидкість перекладу.** На двох тестових фразах звук починався через 1,0 і 1,8 с з Opus 5.5 та через 0,8 і 1,1 с
з Haiku 5.5. На цих фразах переклади обох моделей вийшли майже однаковими.

**Витрати.** Програма витрачає кредити ElevenLabs на розпізнавання й озвучення, а гроші з рахунку Anthropic на
переклад. Тому не лишай її запущеною без потреби.

## Клонування голосу

ElevenLabs уміє робити клон голосу двома способами, і план Creator дозволяє обидва.

*Миттєвий клон* (Instant Voice Cloning) ElevenLabs будує за кілька секунд із запису на 1–2 хвилини. Модель при
цьому не донавчається: вона лише запам'ятовує, як звучить голос, тому схожість добра, але не ідеальна. Саме цей
спосіб підтримує програма.

*Професійний клон* (Professional Voice Cloning) — це донавчання моделі на твоїх записах загальною тривалістю від
30 хвилин до кількох годин. Він звучить значно точніше, але готується кілька годин, і перед цим ElevenLabs просить
підтвердити, що голос твій: прочитати в мікрофон показану фразу. Робиться він у кабінеті на elevenlabs.io, у
розділі Voices.

Клонувати можна лише власний голос або голос людини, яка на це погодилась. Так вимагають правила ElevenLabs.

### Миттєвий клон за чотири кроки

1. Запиши зразок голосу. Програма покаже рівень звуку й відлік часу, а Ctrl+C зупинить запис раніше:

   ```powershell
   .\target\release\live-interpreter.exe record samples\voice.wav --seconds 90
   ```

   Говори так, як говоритимеш із перекладачем: природно, своїм звичайним тоном. Записуй мовою, якою говориш
   вільно, тобто українською. Клон копіює все, що чує в записі: темп, вагання, дихання й акцент. Тому зразок,
   прочитаний мовою, якою ти не володієш, навчив би його говорити невпевнено. Запиши в тихій кімнаті, без музики
   й телевізора, тим самим мікрофоном, яким потім користуватимешся. Сядь приблизно за 20 см від мікрофона.
   ElevenLabs радить, щоб під час мовлення рівень був від −23 до −18 дБ, і програма після запису скаже, чи це
   вдалося. Напис «ПЕРЕВАНТАЖЕННЯ» означає, що треба говорити тихіше або відсунути мікрофон. Можна записати
   кілька файлів і передати їх усі. Записи довші за 2–3 хвилини, за словами ElevenLabs, майже нічого не додають.

2. Створи голос на акаунті:

   ```powershell
   .\target\release\live-interpreter.exe clone --name "Мій голос" samples\voice.wav
   ```

   Якщо в записі чутно фоновий шум, додай `--remove-noise`, і ElevenLabs прибере його перед клонуванням.

3. Перевір клон без мікрофона. Команда `say` перекладе фразу й промовить її твоїм голосом:

   ```powershell
   .\target\release\live-interpreter.exe say "Привіт, це мій голос японською" --voice "Мій голос"
   ```

4. Запусти перекладач із цим голосом:

   ```powershell
   .\target\release\live-interpreter.exe run --voice "Мій голос"
   ```

Клон, записаний українською, говорить японською твоїм тембром, але може переносити в неї й особливості твоєї
вимови. Схожість дуже залежить від моделі озвучення. На першому клоні `eleven_flash_v2_5`, яку перекладач
використовує за замовчуванням, звучала зовсім не схоже, а `eleven_v4` — помітно ближче. ElevenLabs теж описує
саме v4 як модель для точного відтворення клонів. Тому з клоном запускай перекладач із `--tts-model eleven_v4`,
хоча звук тоді починається пізніше. Якщо результат усе одно не подобається, перезапиши зразок гучніше й чистіше. Видалити клон можна в кабінеті ElevenLabs у розділі Voices.

## Будова

| Файл | Що робить |
|---|---|
| `src/main.rs` | команди, запуск ланцюжка й вивід у консоль |
| `src/audio.rs` | мікрофон, відтворення й зміна частоти дискретизації (бібліотека cpal) |
| `src/stt.rs` | розпізнавання мовлення через WebSocket Scribe realtime |
| `src/translate.rs` | переклад через Claude Messages API і поділ перекладу на речення |
| `src/tts.rs` | потокове озвучення ElevenLabs |
| `src/voices.rs` | пошук голосів, миттєвий клон і запис зразка |

Офіційних бібліотек ElevenLabs і Anthropic для Rust немає, тому програма звертається до обох сервісів напряму через
HTTP і WebSocket.
