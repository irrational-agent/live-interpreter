# live-interpreter

Синхронний перекладач. Ти говориш у мікрофон українською, а програма за секунду-дві промовляє те саме японською
або іншою мовою. Озвучувати переклад вона може готовим голосом ElevenLabs або клоном твого власного голосу.
Переклад можна подавати іншим програмам як мікрофон і показувати в чатбоксі VRChat.

Програма має вікно з темною темою, яке показує твої фрази та їхній переклад, а над кандзі японського перекладу
пише фуріґану, тобто читання хіраґаною. Те саме можна робити й з терміналу.

## Як це працює

Програма передає звук із мікрофона в Scribe, сервіс розпізнавання мовлення від ElevenLabs. Scribe повертає текст
ще під час мовлення, і програма показує його в рядку з трьома крапками. Коли ти робиш паузу (за замовчуванням 0,7 с),
Scribe вважає фразу завершеною й надсилає її остаточний текст.

Завершену фразу перекладає Claude. Разом із нею програма передає три попередні фрази, щоб переклад тримав
зв'язок із тим, що вже прозвучало. Claude повертає переклад частинами, і щойно в ньому закінчується речення,
програма відправляє це речення на озвучення в ElevenLabs. Звук починає грати з перших байтів, які приходять у
відповідь, тому перше речення звучить ще до того, як Claude допише решту.

Розпізнавання, переклад і озвучення працюють паралельно, тож наступну фразу програма слухає вже тоді, коли
попередня ще перекладається.

Перекладати слово за словом програма не намагається. В японській дієслово стоїть у кінці речення, тому переклад
можна почати лише тоді, коли думка вже прозвучала. Через це переклад іде на фразу позаду мовця, як і в живого
синхронного перекладача.

На тестових фразах звук починався через 1–2 с після того, як Scribe завершував фразу. До цього додається сама
пауза, за якою Scribe розуміє, що фраза закінчилась.

## Що потрібно

- Windows 10 або 11. Програма бере японські й китайські шрифти з тих, що постачаються з Windows.
- Rust, встановлений через [rustup](https://rustup.rs), разом із Visual Studio Build Tools, які rustup пропонує
  поставити.
- Акаунт [ElevenLabs](https://elevenlabs.io) із ключем API. ElevenLabs розпізнає мовлення й озвучує переклад і
  списує за це кредити. Клон власного голосу безкоштовний план не дозволяє, для нього потрібен платний.
- Ключ [Claude API](https://platform.claude.com/settings/keys) і гроші на рахунку Anthropic, бо переклад робить
  Claude.
- Мікрофон і навушники. Voicemeeter потрібен лише тоді, коли переклад має звучати як мікрофон для VRChat чи іншої
  програми.

## Встановлення

Завантаж код і перейди в його теку:

```powershell
git clone https://github.com/irrational-agent/live-interpreter.git
```

```powershell
cd live-interpreter
```

Програмі потрібні два ключі. Ключ ElevenLabs відповідає за розпізнавання й озвучення, а ключ Claude API — за
переклад. Обидва зберігаються у файлі `.env.local` у теці проекту, який не потрапляє в git. Записати ключ можна
скриптом, який питає його в терміналі й не показує на екрані. Команди нижче запускай із теки проекту:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\set-key.ps1
```

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\set-key.ps1 -Name ANTHROPIC_API_KEY
```

Зібрати програму:

```powershell
cargo build --release
```

Збірка дає дві програми в `target\release\`: `live-interpreter-gui.exe` з вікном і `live-interpreter.exe` для
терміналу. Ключі обидві шукають у `.env.local` поточної теки або теки проекту, тож запускати їх можна з будь-якого
місця. Поки вікно відкрите, Windows не дає замінити його файл, тому перед новою збіркою вікно треба закрити.

Ярлик «Синхронний перекладач» на робочому столі створює скрипт:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\install-shortcut.ps1
```

## Вікно

Кнопка «Почати слухати» вмикає мікрофон, а «Зупинити» вимикає його разом з усім ланцюжком. Кожна завершена фраза
з'являється окремою карткою: зверху твої слова, під ними переклад. Поки Claude перекладає, на місці перекладу
пульсує сіра смужка. Фуріґану програма отримує окремим запитом до Claude, тому вона з'являється приблизно на
секунду пізніше за сам переклад і озвучення не затримує. Внизу картки видно, скільки тривав переклад і через
скільки після кінця фрази пішов звук. Фразу, яку ти ще говориш, вікно показує внизу курсивом.

Мову перекладу перемикають кнопки 日本語 і 中文 у заголовку, а будь-яку іншу мову можна вибрати в налаштуваннях.
Перемикання не зупиняє перекладач: розпізнавання слухає далі, і вже наступна фраза перекладається новою мовою.
Над китайським перекладом програма пише піньїнь, тобто вимову латинкою з позначками тонів, так само як фуріґану над
японським. Китайський текст вікно малює шрифтом Microsoft YaHei, бо в японських шрифтах бракує частини спрощених
ієрогліфів.

Кнопка з шестернею відкриває налаштування. Вікно зберігає їх у `%APPDATA%\live-interpreter\settings.json`. Зміни,
зроблені під час роботи, запрацюють після кнопки «Перезапустити», яка тоді з'являється вгорі.

**Вихід у мікрофон.** Налаштування «Подавати переклад як мікрофон» грає переклад ще й у вибраний пристрій, окрім
навушників. Якщо вибрати Voicemeeter AUX Input, а у Voicemeeter направити смугу AUX на шину, яку VRChat чи інша
програма слухає як мікрофон, ця програма чутиме японський переклад твоїм голосом.

Тут є пастка. Якщо перекладач слухає шину Voicemeeter, наприклад B1, а AUX теж іде в цю шину, перекладач чує
власний переклад і починає перекладати його знову. Так буває, коли шина Voicemeeter стоїть у Windows мікрофоном за
замовчуванням. Щоб цього не сталося, вибери в полі «Слухати мікрофон» фізичний мікрофон, а не шину
Voicemeeter. Інший вихід — увімкнути «Не слухати мікрофон, поки звучить переклад», але тоді слова, сказані під час
перекладу, губляться. Вікно попереджає про цю пастку, коли бачить таке поєднання налаштувань.

**Чатбокс VRChat.** VRChat приймає команди через OSC, тобто короткі повідомлення, які програми надсилають одна
одній по мережі на цьому ж комп'ютері. Коли ввімкнено «Показувати переклад у чатбоксі», програма на час перекладу
вмикає над аватаром індикатор набору, а потім показує в чатбоксі японський текст без звуку сповіщення. VRChat
вміщує в чатбокс до 144 символів і пропускає надто часті повідомлення, тому програма надсилає їх не частіше ніж
раз на 1,6 с і обрізає задовгий текст. У самому VRChat має бути ввімкнено OSC: Action Menu → Options → OSC → Enabled.

## Запуск у терміналі

```powershell
.\target\release\live-interpreter.exe run
```

За замовчуванням програма перекладає з української на японську, перекладає моделлю Claude Opus 5.5 і озвучує
голосом George моделлю Eleven v4 Turbo. Мову, голос і пристрої можна змінити параметрами:

| Параметр | Що робить |
|---|---|
| `--to en` | перекладає на іншу мову (код ISO 639-1: `en`, `de`, `ko`, `zh`…) |
| `--from en` | слухає іншу мову |
| `--voice "Мій голос"` | озвучує вибраним голосом, зокрема твоїм клоном |
| `--headphones` | слухає мікрофон і тоді, коли звучить переклад |
| `--silence 1.0` | змінює паузу, після якої фраза вважається завершеною |
| `--turn-prediction` | завершує фразу тоді, коли модель вирішить, що думка закінчена, а не на першій паузі |
| `--model claude-haiku-5-5` | перекладає швидшою моделлю |
| `--tts-model eleven_flash_v2_5` | озвучує найдешевшою моделлю, але клон голосу нею звучить не схоже |
| `--tts-model eleven_v4` | озвучує найякіснішою моделлю, але звук починається на кілька секунд пізніше |
| `--input-device "USB Microphone"`, `--output-device Headphones` | вибирає мікрофон і вихід звуку за частиною назви |
| `--mic-output "Voicemeeter AUX Input"` | грає переклад ще й у цей пристрій, щоб інші програми чули його як мікрофон |
| `--no-monitor` | не грає переклад у навушники |
| `--vrchat` | показує переклад у чатбоксі VRChat (адресу змінює `--vrchat-address`) |
| `--input-file запис.wav` | бере мову з файлу замість мікрофона |
| `--save-output out\переклад.wav` | зберігає все озвучене у файл |

Список пристроїв показує команда `devices`, а список голосів акаунта — команда `voices`.

**Луна.** Якщо переклад звучить із колонок, мікрофон чує його й передає на розпізнавання, і програма почала б
перекладати сама себе. Щоб цього не сталося, вона не слухає мікрофон, поки звучить переклад, і ще 0,4 с після нього.
Через це слова, сказані в цей час, губляться. У навушниках цієї проблеми немає, тому з ними запускай програму з
`--headphones` і говори без зупинок.

**Швидкість перекладу.** На двох тестових фразах звук починався через 1,0 і 1,8 с з Opus 5.5 та через 0,8 і 1,1 с
з Haiku 5.5. На цих фразах переклади обох моделей вийшли майже однаковими.

**Витрати.** Програма витрачає кредити ElevenLabs на розпізнавання й озвучення, а гроші з рахунку Anthropic на
переклад. Тому не лишай її запущеною без потреби.

## Клонування голосу

ElevenLabs уміє робити клон голосу двома способами, і план Creator дозволяє обидва.

*Миттєвий клон* (Instant Voice Cloning) ElevenLabs будує за кілька секунд із запису на 1–2 хвилини. Модель при
цьому не донавчається: вона лише запам'ятовує, як звучить голос, тому схожість добра, але не ідеальна. Саме цей
спосіб підтримує програма.

*Професійний клон* (Professional Voice Cloning) — це донавчання моделі на твоїх записах загальною тривалістю від
30 хвилин до кількох годин. Він звучить значно точніше, але готується кілька годин, і перед цим ElevenLabs просить
підтвердити, що голос твій: прочитати в мікрофон показану фразу. Робиться він у кабінеті на elevenlabs.io, у
розділі Voices.

Клонувати можна лише власний голос або голос людини, яка на це погодилась. Так вимагають правила ElevenLabs.

### Миттєвий клон за чотири кроки

1. Запиши зразок голосу. Програма покаже рівень звуку й відлік часу, а Ctrl+C зупинить запис раніше:

   ```powershell
   .\target\release\live-interpreter.exe record samples\voice.wav --seconds 90
   ```

   Говори так, як говоритимеш із перекладачем: природно, своїм звичайним тоном. Записуй мовою, якою говориш
   вільно, тобто українською. Клон копіює все, що чує в записі: темп, вагання, дихання й акцент. Тому зразок,
   прочитаний мовою, якою ти не володієш, навчив би його говорити невпевнено. Запиши в тихій кімнаті, без музики
   й телевізора, тим самим мікрофоном, яким потім користуватимешся. Сядь приблизно за 20 см від мікрофона.
   ElevenLabs радить, щоб під час мовлення рівень був від −23 до −18 дБ, і програма після запису скаже, чи це
   вдалося. Напис «ПЕРЕВАНТАЖЕННЯ» означає, що треба говорити тихіше або відсунути мікрофон. Можна записати
   кілька файлів і передати їх усі. Записи довші за 2–3 хвилини, за словами ElevenLabs, майже нічого не додають.

2. Створи голос на акаунті:

   ```powershell
   .\target\release\live-interpreter.exe clone --name "Мій голос" samples\voice.wav
   ```

   Якщо в записі чутно фоновий шум, додай `--remove-noise`, і ElevenLabs прибере його перед клонуванням.
   Перед завантаженням програма переводить запис у 24 кГц, бо ElevenLabs не приймає файли понад 11 МБ.
   Тихий запис вона заодно підсилює до приблизно −20 дБ, але не більше, ніж дозволяє запас до перевантаження.
   Підсилення не прибирає шуму й відлуння, тому записати гучніше одразу все одно краще.

3. Перевір клон без мікрофона. Команда `say` перекладе фразу й промовить її твоїм голосом:

   ```powershell
   .\target\release\live-interpreter.exe say "Привіт, це мій голос японською" --voice "Мій голос"
   ```

4. Запусти перекладач із цим голосом:

   ```powershell
   .\target\release\live-interpreter.exe run --voice "Мій голос"
   ```

Клон, записаний українською, говорить японською твоїм тембром, але може переносити в неї й особливості твоєї
вимови. Схожість дуже залежить від моделі озвучення. На першому клоні `eleven_flash_v2_5` звучала зовсім не
схоже, а `eleven_v4` — помітно ближче. ElevenLabs описує саме моделі v4 як такі, що точно відтворюють клони.
Тому перекладач за замовчуванням озвучує моделлю `eleven_v4_turbo`: це версія v4 для живого мовлення, яка
починає звучати майже так само швидко, як flash. Якщо результат усе одно не подобається, перезапиши зразок
гучніше й чистіше. Видалити клон можна в кабінеті ElevenLabs у розділі Voices.

## Будова

| Файл | Що робить |
|---|---|
| `src/main.rs` | програма для терміналу: команди й вивід у консоль |
| `src/bin/live-interpreter-gui.rs` | програма з вікном, без консолі |
| `src/engine.rs` | ланцюжок «мікрофон → розпізнавання → переклад → озвучення», про який він повідомляє подіями |
| `src/gui/` | вікно: тема, шрифти, фуріґана, елементи керування, іконка |
| `src/audio.rs` | мікрофон, відтворення на кілька виходів одразу й зміна частоти дискретизації (бібліотека cpal) |
| `src/stt.rs` | розпізнавання мовлення через WebSocket Scribe realtime |
| `src/translate.rs` | переклад через Claude Messages API і поділ перекладу на речення |
| `src/tts.rs` | потокове озвучення ElevenLabs через HTTP і вибір способу за моделлю |
| `src/tts_ws.rs` | озвучення моделлю Eleven v4 Turbo через WebSocket, з наперед відкритим з'єднанням |
| `src/voices.rs` | пошук голосів, миттєвий клон і запис зразка |
| `src/ruby.rs` | читання над ієрогліфами (фуріґана, піньїнь): запит до Claude і розбір розмітки `{ієрогліф\|читання}` |
| `src/osc.rs` | повідомлення OSC для чатбоксу VRChat |
| `src/settings.rs` | налаштування, які зберігає вікно |

Офіційних бібліотек ElevenLabs і Anthropic для Rust немає, тому програма звертається до обох сервісів напряму через
HTTP і WebSocket.
